DUSKRAIL / 暮轨   v alpha1.10
========================

一款 3D 铁路运输模拟游戏：驾驶列车在巨大的线路网中完成运输任务，
体验中国铁路与经典机车的魅力。

安装
----
  运行 Duskrail-Setup.exe，按向导安装到当前用户目录，无需管理员权限。
  安装器会自动跟随 Windows 浅色 / 深色模式；桌面快捷方式可在安装时选择。
  从旧 NSIS 版本升级时，会自动清理旧卸载项并保留存档与设置。

运行
----
双击 Duskrail.exe 启动。光敏性癫痫警告已移到安装器，安装时阅读并
选择“我已知晓”后才能继续。启动动画结束后进入主菜单：
  单人游戏  —— 继续游戏 / 加载存档 / 新建存档
  多人游戏  —— 敬请期待
  设置      —— 左侧分类、右侧子项
  退出游戏

存档与更新
----------
  安装器不会删除 user:// 下的存档和设置。Alpha 阶段旧版本存档仍然会
  显示和加载，首次启动会复制到 user://saves_backup 作为备份；旧路线
  里程会按新旧线路总长自动换算。后续 Beta 如需收紧存档兼容，可在
  SaveManager 中关闭 LEGACY_COMPAT，备份文件仍会保留。

画面缩放与 DLSS
---------------
  设置 → 画面 → 3D 缩放 可选择：
    关闭（原生）
    FSR 2.2 质量 / 平衡 / 性能
    DLSS 质量 / 平衡 / 性能（仅 RTX 20 系列及以上）
    DLAA（仅 RTX 20 系列及以上）
  DLSS 需要 NVIDIA RTX 显卡和较新的驱动；非 RTX 显卡不会显示
  DLSS 选项，若存档中保存了 DLSS，会自动回退到 FSR 2.2 质量。
  DLSS 目前仅支持 Super Resolution 与 DLAA，不包含帧生成和光线重建。

行车操作（默认）
----------------
  W / ↑            档位向上（P3→P2→P1→N→D1→D2→D3→D4→D5）
  S / ↓            档位向下（顺序相反）
  A / ←            打开 / 关闭车门（仅停靠站台且已施加停放制动时）
  D / →            打开 / 关闭车灯
  空格             紧急制动；处于 D5 时立即回到 N 档；步行时跳跃
                   （步行中由 WASD 移动，空格只负责跳跃）
  R                换向
  H                鸣笛
  L                前照灯（同 D）
  O                远光灯（需先开前照灯）
  K                车门（仅站台侧）
  B                停放制动
  X                撒砂
  C                默认视角 / 第一视角（只保留这两种）
  V                视角回正
  F                第一视角下在驾驶座 / 副驾驶座旁坐下
  E                第一视角下离开座椅；车外靠近打开的车门时登车
  P                自动驾驶：选择停靠站点
  T                时间推进
  M                打开 / 关闭全屏大地图（地图内 Esc 返回）
  F5               小地图模式：放大 / 全览
  G                切换前方进路（主线 / 侧线 / 车场）
  F1               界面开关
  F3               调试面板
  F12              截图
  Esc              暂停菜单（内含“保存游戏”）

列车编组（创造模式）
--------------------
  暂停菜单 → 列车编组，或 任务中心 → 车辆编组 → 编辑编组。
  左侧车厢库点击添加；中间编组台点击车厢后可删除、左移或右移。
  新增载客车厢、行李车厢、水罐车厢、平板车厢、敞车与冷藏车厢，
  并与既有集装箱平车、漏斗敞车混合编组。
  双车头：点击编组台右上角“＋ 加挂副机车”，或在编组台第一台机车
  后方的“加挂副机车”卡片上点击，即可组成双机重联。两台 HXD1
  连接在列车最前，动力并联，仍由前车统一操纵。
  客运车厢与货运车厢不能混编；最短可不挂车厢，最长按干线列车限长：
  货运 700 m、客运 500 m。
  “满载”开关会影响总重、载重与运行质量；应用编组后自动保存。

车辆外观
--------
  25T 客车、XL25T 行李车、C70 敞车、C80 漏斗车、G17 水罐车、
  NX70 平车、X6K 集装箱平车与 B23 冷藏车均按实车比例、涂装和
  车体细节重做；货车采用 K6 / K7 三大件转向架，客车采用 209P 式
  转向架。车厢转向架按参考图重做：铸钢侧架收窄到车轮外缘附近，
  端部改为开放式轴箱导框，中央弹簧窗口内保留两组双卷枕簧与
  斜楔减振装置；摇枕横跨两侧架，带心盘、旁承和椭圆减重孔；
  每个轴箱外侧增加可见液压减振器，配橡胶剪切垫和大直径轴箱前盖；
  侧架之间保留弹性下交叉支撑、中拉杆式制动梁、闸瓦和制动缸。
  K6 固定轴距按 1830 mm、车轮按 840 mm 还原；客车 209P 变体使用
  同一套三大件结构，配盘形制动。
  HXD1 机车 Bo-Bo 转向架单独按实车照片重做：箱型侧梁、中央空气弹簧、
  轴箱一系圆簧与垂向减振器、牵引电机和齿轮箱、轴装制动盘与夹钳、
  中心牵引杆、抗侧滚扭杆、制动缸/风缸及电缆软管均逐件建模。
  牵引电机横向居中安装在车轴上，轴端盖正面四颗螺栓随轮对旋转。
  集装箱平车的加强筋、角件和门板已与箱体统一坐标，不再出现
  箱侧护板下探到轨面的错位。25T 客车上沿和窗下增加连续的横向
  金属饰条，车顶增加两道纵向饰条，避免上部装饰条只剩竖向窗框。
  25T 客车新增贯通式内饰：地板、蓝色通道地毯、行李架、顶灯、可透视
  车窗和 2+2 座椅（每排左右各两组、中间为走道）；两端端墙开有真实
  门洞、端门和风琴式贯通道。编组中间的端门打开、风琴通道连接，
  最后一节车厢的后端门关闭。车体、端墙和风琴通道的尺寸均保证人物
  通行，不会落到轨道上。客车侧门改为可动画塞拉门，开门时沿车体
  侧面向车端滑开；门洞增加内门框、门槛和密封条，关闭时门缝不再
  透出车外。
  XL25T 行李车厢增加贯通走廊和两侧货物固定区，可从车厢一端穿到
  另一端，不再被封闭车体挡住。
  客车内壁、窗下墙、窗间柱和顶部饰板完整封闭，从车内不会看到车外
  地形或底架；车厢地面改为哑光地毯，不再出现反光圆斑。
  司机室、引擎室通道和车尾小驾驶室增加完整内侧墙板，走廊两侧不再
  透出车外。

司机室
------
  HXD1 改为单端司机室：只有前部驾驶室，司机室加长，侧门位于
  座椅后方；另一端取消驾驶室、风挡和侧窗，变为带散热百叶与
  尾端格栅的引擎室。前窗与两侧车窗为真实开口，侧窗玻璃改为
  高透低反射，从车外可以看到座椅和操纵台；前窗后方的内侧角窗
  与外侧开口、玻璃尺寸对齐，车外同样能看到内部。第一视角座椅前移到
  前窗后方约 1.6 m，前部车体框和内风挡框在车内保持可见。
  左侧座椅正前方改为液晶速度屏，PWR / CAB 与其余按钮集中到
  操纵台上；鼠标悬停在按钮上会显示功能说明。
  侧门改为塞拉门：先向外平移一个门厚，再沿车体向后缓慢滑开，关门
  按原路径反向回位；车身和内饰均开有真实门洞。
  司机室后墙右侧开了通往引擎室的通廊门；引擎与牵引电机占据左侧，
  右侧留出连续通道，可一路走到车尾的小型调车驾驶室。车尾端墙中央
  有通往客运列车的门洞；后方挂客运车厢时门与风琴通道打开，挂货运
  车厢或没有后继车辆时自动关闭。

车门与步行
----------
  车门只有在列车停稳、停靠站台并施加停放制动后才能打开，且只开
  站台侧。司机室“车门”按钮会同步开启整列站台侧车门；“整列左侧
  车门 / 整列右侧车门”按钮按侧别同步控制司机室门和所有客车侧门。
  只有车体实际与站台重叠的车厢才开门：列车编组超出站台长度时，
  越过站台的车厢侧门保持关闭，不会开门直接对着路基或草地。
  货运站台不再比客运站台额外外移，站台边缘统一靠近车辆；货运场坪
  也补上了可行走碰撞。列车进入侧线/车场轨道时车门不开启，避免对着
  没有站台的一侧开门。
  自动驾驶运行途中车门锁定，到达站点并自动施加停放制动后才能开门。
  行走不是独立视角。满足以下任一条件时，在第一视角按 E 离开座椅：
  列车停稳且停放制动已施加；或自动驾驶已启用并设定了目标站点。
  离开座椅后仍在第一视角：WASD 移动、空格跳跃、Shift 疾跑，鼠标
  环视；屏幕中央显示行走准星。走到座椅旁按 F 坐下，可在驾驶座和
  副驾驶座之间切换。走到打开的站台侧车门即可下到站台；在站台靠近
  任意打开的客车侧门按 E 可重新登车。C 键只在默认视角和第一视角
  之间切换，默认视角不会触发离座。
  从暂停菜单、自动驾驶面板、地图或车辆面板返回游戏时，行走模式会
  自动重新捕获鼠标，不需要再点一次画面。
  列车运行时人物会跟随所在车厢的插值变换，走过端门和风琴通道时
  不会因车体运动而被甩出或卡住。车厢连接处按实际距离连续步行穿过，
  不再在风琴段瞬间跳到下一节车厢。

自动驾驶
--------
  按 P 打开自动驾驶面板，选择目标站点；列车会自动牵引、调速，
  在站台前 500 m 进入 30 km/h 限速，到停车点自动停车并施加
  停放制动。运行中不能开门。再次按 P 可取消或重新选择目标。
  自动驾驶按前方里程选择车站；如果目标在后方，列车会沿环线运行。

车站站厅
--------
  进入站厅后靠近设备按 E：
    自动售票机     取票，10 分钟内有效
    检票闸机       有票时按 E 开闸，闸机门会向两侧滑开
    车站咖啡       花费 ¥15 购买热饮，3 分钟内步行速度提高 20%
  站厅内的两条自动步道会持续运行，站上去会被带动；中间通道仍可正常步行。
  低画质下会减少候车乘客和部分灯光。

任务与自由驾驶
--------------
  暂停菜单 → 任务中心：
    快速任务       系统随机发布的货运任务
    预设任务       8 个固定车次，含集装箱、空车和旅客列车
    自由驾驶       收起当前任务，前往任意车站；可随时继续当前任务
    车库           购买机车车辆
  自由驾驶中列车会停在所选车站停车标并施加停放制动，可直接开门或继续运行。
  旅客列车停站开门后，车厢内会有旅客下车和新旅客上车就座。

行走部
------
  转向架与车体由 CPU 弹簧-阻尼悬挂驱动；过弯和轨缝时车体会自然
  侧倾、起伏，转向架也会随轨道起伏。牵引和制动不再让车体前后点头。
  车体左右摆动采用低频随机噪声，不再按固定节拍重复；进入和驶出弯道时，侧倾会
  平滑过渡，不会瞬间压到最终角度。
  每组转向架按自身轨道切线整体偏转，侧架和两根轮对保持刚性连接，
  不会出现外框单独扭转、轮轴留在原方向的情况。默认追车视角直接
  绑定车辆插值变换，避免车体与视角产生相对抖动。
  行走模式在桥梁、高架和隧道内会自动落到桥面或隧道地板，不会掉进
  水面或山体；站台高度也会被识别，可以直接从车门走上站台。
  WASD 分别对应前、后、左、右移动，空格跳跃，Shift 疾跑。

档位说明
--------
  P3 / P2 / P1     停车制动（由强到弱）
  N                空挡：车辆会随地形溜车
  D1 ~ D5          前进动力（由弱到强）
  新建存档或首次进入默认 P3。

地图与保存
----------
  左下角为缩小后的速度表（表底 200 km/h，底板半透明），右下角为线路
  小地图；按 M 打开全屏大地图，Esc 返回。停车步行时自动隐藏速度表。
  线路约 28.5 km，主线 5 站（山川、临江、青川、雁归、青石），
  青石至山川间另设东环支线 2 站（云溪、石门）；保留多段高架桥和跨湖高架，
  沿线湖泊、水库等水域。
  大地图默认暂停游戏，可在“设置 → 游戏”中改为继续运行。
  自动保存频率可在“设置 → 游戏”中选择 10 / 5 / 3 / 1 分钟。
  删除存档前会弹出“是否删除该档案？”的二次确认。
  “冷车起动（进阶）”开启后，冷车状态按操纵台上的【主电源】即可
  自动完成整备；关闭时整备完成，选档即可发车。

岔道与车场
----------
  线路在临江、青川、雁归设有可进入的侧线。青川站另设三股道车场，
  含车场办公室、集装箱堆场和照明灯柱。
  行驶中按 G 循环选择前方进路：
    主线 → 临江侧线 → 青川车场 1/2/3 道 → 雁归侧线 → 主线
  顶部 HUD 会显示当前选择的进路；列车到达岔区后会自动转入所选线路。
  列车驶出侧线远端后自动回到主线，再次按 G 可选择下一条进路。

测试模式
--------
  新建存档 → 测试模式。专用约 4.2 km 试验环线：两端 95 m 半径
  180° 回头弯、长蛇形连续 S 弯和约 9% 的连续起伏坡道，25.5 m 客车
  车体最小静态间隙约 8.5 cm，处于可通过但不穿模的极限附近。固定编组为
  HXD1 + 2 辆 25T 客车 + 2 辆 X6K 集装箱平车 + 1 辆 C80 漏斗车，
  同时测试 HXD1、209P、K6 与 K7 转向架。动力锁定为 1800 kN，
  发动机和变速箱不可调整；车辆整备完成后可直接选档发车。

车辆改装
--------
  暂停菜单 → 改装车间，页面分为“改装配件”和“外观涂装”。
  改装配件内分为大件（发动机、传动方式、变速箱）与附件
  （装饰和照明小件）；HXD1 的传动方式为固定交—直—交电传动。
  附件新增“车体侧裙板”：沿车头两侧下部铺设装饰裙板，在前后
  转向架位置留出梯形缺口，不遮挡轮对和转向架。
  3D 预览：右键拖动旋转，滚轮缩放，“复位”恢复默认视角。
  车间已扩大，并新增“行走模式”：进入后用 WASD 移动、Shift 加速、
  鼠标环视，可贴近车体绕车检查；按 Esc 退出行走，再按 Esc 关闭页面。
  引擎影响牵引力、最高速度与整备质量；皮肤会立即应用到机车。
  点击“应用改装”后会自动保存到当前档案。

启动与读取
----------
  地形高度采样已改为多线程并行，城市窗户与道路构件使用 MultiMesh，
  转向架/植被/车站的网格构建也做了合并与批处理。相同测试环境下，
  完整世界生成由约 60 秒降至约 23 秒，线路、车站、城市和植被内容
  均保留。进入存档时仍会完整构建当前线路。

存档与设置位于  %APPDATA%\Godot\app_userdata\Duskrail\
从旧版本升级时，会自动迁移原有存档与设置。
卸载：Windows 设置 → 应用 → Duskrail 暮轨，或运行安装目录下的
unins000.exe。
